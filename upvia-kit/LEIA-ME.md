# Kit de ferramentas Claude para o UpVia

Copiar a pasta `.claude/` daqui para a raiz do repositório do UpVia.
A partir daí, qualquer sessão do Claude Code nesse projeto carrega:

- **Superpowers** (obra/superpowers): planear antes de codar, testes, depuração, revisão.
- **UI UX Pro Max** (nextlevelbuilder/ui-ux-pro-max-skill): estilos, paletas, tipografia, regras de UX.
- **Apple Design** (dickwu/apple-design-skill, copiado em `.claude/skills/apple-design`): revisão segundo as Human Interface Guidelines da Apple.

Deixadas de fora de propósito (sobrepõem-se a estas, são irrelevantes para o UpVia ou precisam de chaves pagas):
GStack, Ruflo, ECC, Taste-Skill, Awesome Design, Impeccable, Claude-Mem, Ponytail, Hyperframes,
Humanizer, Obsidian Skills, Banana Claude, Screenshot to Code, Scrapegraph AI, Book to Skill, Public APIs.
